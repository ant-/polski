# Polski B1 Exam Sources

This directory contains Polish B1 (Biegłość na poziomie B1) exam materials from official certification body.

## Source

All files are sourced from: **https://certyfikatpolski.pl/wp-content/uploads/**

## Directory Structure

Each exam session is organized in a directory named `YYYY-MM` containing three standardized files:

- `test.pdf` - Exam answer sheet (arkusz egzaminacyjny)
- `audio.mp3` - Audio recording (plik dzwiekowy)
- `transcript.pdf` - Transcript of recordings (transkrypcja)

## Notes

- **Naming variations**: Original filenames use different conventions (lowercase 2024/2023, mixed case 2022, capitalized 2021)
- **File variant**: One audio file uses "pilk_dzwiekowy" (typo), one has double `.mp3.mp3` extension
- **Transcript naming**: 2022-2021 files use "Transkrypcja_nagran", 2023-2024 use "transkrypcja"
